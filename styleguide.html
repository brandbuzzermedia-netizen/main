Colour

Ten tokens, defined once in :root in styles.css. Always reference the variable, never a raw hex — that's what keeps a colour change to one line.

--cream#fff2dcDefault page background
--cream-lift#fffaf0Cards and raised surfaces
--yellow#ffb933Primary accent, highlights, buttons
--yellow-deep#ff9600Accent shade, small emphasis marks
--green#196144Headings, borders, dark sections
--green-2#3e5d48Secondary green, muted copy on yellow
--white#ffffffForm inputs only
--grey#999999Muted labels, sector lines
--char#262626Body copy inside components
--ink#191816Default body text
Pairing rule. Green and cream are the only pair used at full strength in both directions. Yellow is an accent, never a text colour on cream — it fails contrast. On green backgrounds, body copy is cream at 86% opacity.

Typography

Two families. Headings carry the brand's character; body text stays out of the way.

Families

--font-display: "Bunga", "Alfa Slab One", "Cooper Black", Georgia, serif;
--font-body:    "Neue Leiden", "Archivo", "Segoe UI", system-ui, sans-serif;
Bunga and Neue Leiden aren't loaded yet. Neither is on Google Fonts, so the site ships with the closest free matches — Alfa Slab One and Archivo — with the real names first in the stack. Drop Bunga.woff2 and NeueLeiden.woff2 into assets/fonts/ and uncomment the @font-face block at the top of styles.css to switch over.

Five vector files, all extracted from the brand kit. Each viewBox is fitted to the artwork's own bounds, so they can't clip at any size — set a height and let the width follow.

Two bees, one shape. bee.svg has green linework, so it needs a cream or yellow ground — that's why the loading screen puts it inside a cream disc. bee-yellow.svg is the same artwork in yellow and white, for the green hero.

Surfaces & shape

One border, one shadow, one radius. The hard offset shadow is what gives the site its sticker-like feel — it's a solid colour, never a blur. 

--border:    2.5px solid var(--green);
--shadow:    5px 6px 0 rgba(25, 97, 68, .9);
--shadow-lg: 9px 10px 0 rgba(25, 97, 68, .9);   /* hover / featured */
--radius:    26px;
--maxw:      1180px;                            /* .wrap max width */
--ease:      cubic-bezier(.22, .68, .3, 1);
Default: --shadow
Raised: --shadow-lg
Cards lift on hover by translating -3px, -4px and swapping to the larger shadow. Buttons do the reverse on :active — they press into the page.

Hero

Both hero types — .hero on the home page and .page-hero on inner pages — sit on green with a drifting honeycomb lattice, white headings and cream body copy. The kicker flips to yellow-on-green, and hero buttons use .btn--yellow (a green button would disappear).

Motion & accessibility

Reveal on scroll

Add class="reveal" to any block. It fades up when it enters the viewport, staggered 70ms apart within a group.

Rules that aren't optional

  • Reduced motion. Every animation is disabled under prefers-reduced-motion, and the loading screen advances immediately. Anything new must respect it.
  • Focus is visible. A 3px yellow-deep outline with 3px offset, set globally on :focus-visible. Never remove it.
  • Contrast. Yellow is a background or a large-display colour, never small text on cream.
  • Icons carry labels. Icon-only links need aria-label; decorative SVG gets aria-hidden="true".
  • Images need dimensions. Set width/height so the page doesn't jump while loading.
  • The loading screen must always clear. Two fallback timers (4s and 7s) guarantee it, plus a session flag so it only runs once per visit.

Editing the site

Don't hand-edit the HTML pages. The six pages are generated from one shared template so the header, footer and <head> can't drift apart. Edit tools/build.py, then run python3 tools/build.py. Editing index.html directly gets overwritten on the next build. 
styles.css        design tokens + every component style
script.js         loader, nav, reveals, counters, accordion, form
tools/build.py    page content and the shared shell — edit here
assets/           logo artwork (SVG)
assets/work/      client screenshots and identity boards (WebP)
styleguide.html   this page — standalone, not regenerated by the build
